# GPT Image 2.6、SVG 和原生 GIF 适配

> 本文保留 2026-11-05 的历史适配记录。当前行为以 [2026-11-11 原生输出说明](2026-11-11-gpt-image-2.6-native-output.md)为准：GIF 默认 **9 帧**，帧数范围 **2–16**；SVG 已改走 **Images generations** 接口，仅支持纯文字生成。下文的「默认 20 帧」「SVG 聊天接口」和 SVG 图生图验证均不代表当前能力。

## 上游 GIF 教程同步（2026-11-05）

依据用户提供的 Klong 最新公告和 cURL 示例同步。公开文档入口为 https://docs.klong.lat/docs/image/gpt-image-2 ，查阅时仍主要介绍 PNG/JPEG/WebP，尚未补充 GIF 动画参数；以下默认值取自公告示例，未把它们称为服务端限制。

- 原生 GIF 通过 Images generations 接口发送 `output_format: "gif"`、`frame_count`、`frame_duration_ms`、`response_format: "url"`、`stream: false`，取代此前只靠提示词请求 GIF 的兼容方案。即使启用普通生图流式选项，原生 GIF 也不发送流式或 partial_images 参数。
- 开启原生 GIF 后，底部工具栏出现「帧数」（默认 20）和「每帧时长」（默认 200 毫秒）。两项设置单独持久化，随任务保存并用于重新生成；关闭后隐藏并不传给普通生图，与网格模式的本地帧间隔独立。
- 前后端校验正整数；旧设置缺少字段时使用示例默认值。原生 GIF 仍仅限 GPT Image 2.6 系列，仍拒绝参考图。
- 原生 GIF 与 SVG 开关位于各自工作台的底部工具区，使用 16px 高、黑白灰配色的开关；工具栏支持换行。
- SVG 保持原聊天接口的实现，本次 GIF 公告没有提供 SVG 新协议，未据此变更 SVG 请求。
- 后端原生输出回归 19 项、前端 GIF 工作流与请求回归 10 项、工具栏交互回归 3 项通过，覆盖自定义值透传、任务恢复和重试、模式切换、非法值、URL 下载、原始字节保存，以及旧模型和参考图限制。
- 两版 Next.js 生产构建（含 TypeScript）通过。
- 浏览器连接不可用，本轮界面通过组件交互测试验证。请求链路使用本地上游模拟服务，未将其称作 Klong 真实生成成功。下文早先的上游探测记录仅反映当时渠道状态。

## 功能

- 添加 GPT Image 2.6、GPT Image 2.6 Pro 模板，默认模型分别为 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst-pro`。API 地址和密钥使用用户的供应商配置；已有模型记录保留实际模型 ID、API 地址和密钥。
- 根据实际上游模型 ID 与 OpenAI 协议启用 2.6 能力，兼容自定义配置名称。保留高级质量参数、独立 Markup，以及 Pro 自定义分辨率；历史重试保留合法自定义尺寸和输出格式。
- 生图工作台增加 SVG 开关，串联提交、任务保存、错误包装中的 SVG 提取、原字节缓存、预览和 `.svg` 下载。SVG 模式不同时发送 Markup 标注。
- 动图区域选择 2.6 时默认开启原生 GIF，只接收文字描述，不使用参考图、网格模板和手动切帧。上传入口隐藏且粘贴不生效；旧参考图不会进入生成或提示词优化请求。服务端拒绝带参考图或图生图模式的原生 GIF 请求。关闭开关后恢复网格流程。
- 识别实际文件字节，保留真实 GIF/SVG 的格式和原始内容。GIF 显示实际帧数；上游返回静态 PNG 时保留 PNG 并提示。SVG 图片响应带 `nosniff` 和 CSP sandbox。
- 打包清单补齐 `gpt-image-markup.js` 和 `image-output.js`；部署依赖测试同时检查后端文件和插件运行目录。
